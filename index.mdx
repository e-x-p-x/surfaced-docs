Surfaced tracks how AI assistants answer the questions your buyers ask, and shows where your brand is named, where a competitor is named instead, and which pages the assistants cite when they answer.

If you are setting up a workspace for the first time, start with the [Quickstart](/quickstart). If you already have results and want to know what a number means, start with [Metrics](/metrics/overview).

## How it works

You give Surfaced a set of prompts: the questions a buyer would type. Surfaced asks them of the assistants on a schedule, reads the answers, and records three things each time: whether you were named, who else was named, and which pages were cited as the source.

That record is what every screen in the app is built on. Nothing is modelled or estimated from search volume; a number in Surfaced is a count of answers that came back.

## If you only read one thing

The number most people want on day one is whether they are being recommended. That lives in [Metrics](/metrics/overview), which defines each figure and shows the calculation, so you can tell the difference between being absent from an answer and being absent from the data.

<Note>
  Results need a few days of answers before a trend means anything. One run tells you what one assistant said once.
</Note>
